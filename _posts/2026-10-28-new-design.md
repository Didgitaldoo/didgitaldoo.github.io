# A fresh look for Didgitaldoo

The website has a new design: warm colors, a cleaner typography, and cards for the main sections and the didge database. It also works better on phones.

The source code is open. If you want to try the site locally, there is now a Docker Compose setup, so you don't need to install Jekyll. See the [README](https://github.com/didgitaldoo/didgitaldoo.github.io) for details.
